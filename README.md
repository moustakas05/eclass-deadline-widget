# UOWM Open eClass Deadline Widget

Ένα ελαφρύ desktop widget για Windows (σε Python & CustomTkinter) που συνδέεται στο Open eClass του Πανεπιστημίου Δυτικής Μακεδονίας (ΠΔΜ) μέσω CAS SSO, εντοπίζει τις ενεργές προθεσμίες εργασιών και τις εμφανίζει με live αντίστροφη μέτρηση.

## Χαρακτηριστικά
- **Αυτόματη Σύνδεση (CAS SSO):** Εισαγωγή ιδρυματικών στοιχείων μέσω γραφικού παραθύρου με δυνατότητα τοπικής αποθήκευσης (.env).
- **Έξυπνη Σάρωση & Φιλτράρισμα:** Αναγνωρίζει ελληνικές ημερομηνίες, αφαιρεί αυτόματα όσες εργασίες έχουν υποβληθεί ή λήξει.
- **Διαχείριση Παραθύρου:** Δυνατότητα καρφιτσώματος (Pin), ελαχιστοποίησης στο παρασκήνιο ή αυτόματης ελαχιστοποίησης όταν αλλάζετε εφαρμογή.
- **Manual Sync:** Χειροκίνητος επανασυγχρονισμός με το eClass στο παρασκήνιο.

## Τρόπος Χρήσης (Έτοιμο Εκτελέσιμο .exe)
1. Κατεβάστε το τελευταίο .zip από την ενότητα Releases.
2. Αποσυμπιέστε το και βεβαιωθείτε ότι τα runner.exe και config.json είναι στον ίδιο φάκελο.
3. Τρέξτε το runner.exe και εισαγάγετε τα ιδρυματικά σας στοιχεία.
